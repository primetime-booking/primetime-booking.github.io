# Цель

Перенести клиентский PrimeTime в независимый публичный GitHub Pages `primetime-booking/primetime-booking.github.io`, не затрагивая PrimeTime Pro и «Анатомию массажиста».

# Сделано

- Создан отдельный публичный репозиторий организации.
- Перенесены клиентские страницы и необходимые общие зависимости из `minuta-online-booking/`.
- Добавлены отдельные manifest, service worker/cache `primetime-client-v1` и Pages workflow.

# Проверено

- Статические проверки клиентского состава, JavaScript и основного booking-flow проходят.
- Локальный сайт загрузил реальные услуги и свободное время; путь «услуга → время → контакты» пройден без создания записи.
- Интерфейс проверен на 390, 760 и 1440 px без горизонтального переполнения.
- Service worker `sw.js?v=1` зарегистрирован и загрузил собственный клиентский набор PWA-ресурсов.

# Зафиксированные решения

- Старый адрес тренажёра `anatomy-trainer/#/home` не изменяется.
- Кабинет исполнителя остаётся в исходном репозитории; клиентские ссылки на него ведут на прежний адрес.
- Используется существующий публичный Supabase backend без service-role ключей и изменений данных.
